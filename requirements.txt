# ResQVision MVP - Python dependencies
# Python 3.13 verified. Install with:  pip install -r requirements.txt
#
# ---------------------------------------------------------------------------
# IMPORTANT - GPU USERS: install the CUDA build of PyTorch FIRST.
# Plain `pip install torch` gives you the CPU-only wheel on Windows, and the
# pipeline would then silently run in FP32 on CPU instead of FP16 on the GPU.
#
#   CUDA 12.4 (Windows / Linux):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
#   CPU only:
#     pip install torch torchvision
#
# Verify afterwards:  python -c "import torch; print(torch.cuda.is_available())"
# ---------------------------------------------------------------------------
